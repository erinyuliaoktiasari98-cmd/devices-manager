# Contributing to Devices Manager

Terima kasih telah tertarik untuk berkontribusi pada **Devices Manager**! 🎉

## 📋 Petunjuk Kontribusi

### 1. Fork Repository
- Klik tombol "Fork" di sudut kanan atas repository ini.

### 2. Clone Repository
```bash
git clone https://github.com/YOUR_USERNAME/devices-manager.git
cd devices-manager
```

### 3. Buat Branch Baru
```bash
git checkout -b feature/nama-fitur
# atau
git checkout -b fix/nama-fix
```

### 4. Buat Perubahan
- Edit code sesuai kebutuhan
- Pastikan code mengikuti style guide yang ada
- Test perubahan Anda secara menyeluruh

### 5. Commit Perubahan
```bash
git add .
git commit -m "feat: deskripsi singkat perubahan"
```

**Format Commit Message:**
- `feat:` untuk fitur baru
- `fix:` untuk perbaikan bug
- `docs:` untuk dokumentasi
- `style:` untuk perubahan formatting
- `refactor:` untuk refactoring code

### 6. Push ke Fork Anda
```bash
git push origin feature/nama-fitur
```

### 7. Buat Pull Request
- Buka repository di GitHub
- Klik "Compare & pull request"
- Deskripsi PR Anda dengan detail
- Submit PR

## 🎯 Guidelines

### Code Style
- Gunakan **Kotlin** untuk semua source code
- Follow [Kotlin Coding Conventions](https://kotlinlang.org/docs/coding-conventions.html)
- Gunakan **Jetpack Compose** untuk UI

### Testing
- Tambahkan unit tests untuk logic baru
- Pastikan semua tests lolos sebelum submit PR

### Documentation
- Update README jika ada fitur baru
- Tambahkan comments untuk logic yang kompleks
- Update CHANGELOG jika ada perubahan signifikan

## 🐛 Melaporkan Bug

1. **Cek issues yang sudah ada** - jangan membuat duplikat
2. **Buat issue baru** dengan template berikut:
   - Deskripsi bug
   - Steps to reproduce
   - Expected behavior
   - Actual behavior
   - Device/OS info

## 💡 Saran Fitur

1. **Buka discussion atau issue** dengan label `enhancement`
2. **Jelaskan** mengapa fitur ini diperlukan
3. **Provide examples** jika memungkinkan

## ✅ Checklist Sebelum Submit PR

- [ ] Code mengikuti style guide
- [ ] Tests lolos
- [ ] Documentation updated
- [ ] No new warnings
- [ ] Branch up to date dengan main

## 📞 Pertanyaan?

Terbuka untuk diskusi di:
- GitHub Issues
- GitHub Discussions
