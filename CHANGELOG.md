# Changelog

Semua perubahan penting dari project ini akan didokumentasikan dalam file ini.

Format berdasarkan [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
dan project ini mengikuti [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial project setup dengan struktur MVVM + Clean Architecture
- Agent App dan Monitor App dengan UI dasar menggunakan Jetpack Compose
- GitHub Actions workflow untuk auto-build APK
- ProGuard rules untuk optimasi dan obfuscasi
- AndroidManifest.xml untuk kedua aplikasi
- CONTRIBUTING.md untuk panduan kontribusi
- ARCHITECTURE.md untuk dokumentasi arsitektur
- CHANGELOG.md ini

### Planned
- Implementasi WebSocket untuk real-time communication
- Camera streaming dengan CameraX
- Screen sharing functionality
- GPS location tracking dengan Google Play Services
- QR Code generation dan scanning
- Authentication dan security layer
- Unit dan integration tests
- Database layer dengan Room
- Improved UI/UX dengan Material Design 3
